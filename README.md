# Roblox Passive-Income Portfolio

**Three complete, market-researched games** built on one verified engine, each targeting a
different discovery lane — strategy and the honest revenue math live in
[`PORTFOLIO.md`](PORTFOLIO.md):

1. **Crack a Geode! [Mining Simulator]** (this folder) — collection idle: mine geodes, crack
   them in a slow-mo rarity reveal, grow crystals on racks **while offline**, rebirth into
   deeper layers. → [`SETUP.md`](SETUP.md)
2. **Reel a Relic! [Fishing Simulator]** (`games/reel-a-relic/`) — the engine re-themed into
   the hot fishing lane with a bite-timing catch mechanic. → [`games/reel-a-relic/SETUP.md`](games/reel-a-relic/SETUP.md)
3. **Easy Obby: +1 Jump** (`games/easy-obby/`) — search-evergreen obby where every stage adds
   +1 jump power until you leap whole sections; zero paid RNG. → [`games/easy-obby/SETUP.md`](games/easy-obby/SETUP.md)

Each game is self-contained with its own ready-to-open `build/game.rbxlx`.

## About the root game (Crack a Geode)

All replayability is systemic (procedural shop rotation, random luck events, infinite rebirth
ladder, 48-entry collection matrix) — no weekly content treadmill.

**Start here → [`SETUP.md`](SETUP.md)** — publish, monetize, and launch, step by step.

## What's in the box

- `build/game.rbxlx` — ready-to-open place file (Studio → Open from File → Publish). The whole
  world is generated by code at server start; no manual building needed.
- `src/shared/` — config (crystals, balance, monetization IDs) + the rarity math that powers both
  the server rolls and the player-facing odds panel (single source of truth = compliant by
  construction).
- `src/server/` — data (ProfileStore, session-locked), mining, cracking (with first-session pity),
  offline growth racks, rebirths, clock-synced shop, random events, streaks, monetization with
  idempotent receipts, PolicyService gating, leaderboards, analytics funnel.
- `src/client/` — mobile-first UI: HUD, crack reveal, racks, shop, Robux store, collection index,
  rebirth screen, toasts, event banner.
- `marketing/` — paste-ready store-page copy and the TikTok/Shorts launch scripts.
- `tests/` — math tests (odds compliance invariants, roll distribution, economy) runnable with the
  standalone Luau CLI: `sh tests/run.sh`.
- `.github/workflows/ci.yml` — CI: strict analysis + tests + rebuilds `build/game.rbxlx` on every
  push (auto-commits it when source changed).

## Key design decisions

- **Built for the 2026 discovery algorithm:** daily-return hooks everywhere (offline earnings,
  streaks with milestones, collection completion, daily deals) because 28-day retention now
  drives free homepage distribution.
- **Compliance by construction:** every random roll and every displayed percentage come from the
  same `RarityMath` module; paid-random surfaces are policy-gated with a deterministic storefront
  fallback; all Robux products are deterministic.
- **Tuning without code:** the entire economy lives in `src/shared/Config/Balance.luau`; new
  content is one row in `src/shared/Config/Crystals.luau` (= 6 new collectibles per row).

## Developing

```sh
rokit install          # installs rojo, stylua, selene (pinned in rokit.toml)
rojo serve             # live-sync src/ into Studio via the Rojo plugin
rojo build -o build/game.rbxlx   # rebuild the committed place file
```

Static checking used in CI/dev: `luau-lsp analyze --sourcemap sourcemap.json` with Roblox API
definitions (the codebase is `--!strict` and clean), plus StyLua/selene configs included.
