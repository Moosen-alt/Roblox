# Crack a Geode — a passive-income Roblox game (plan)

## Context

You want a Roblox game that earns on the side while you focus on other projects: build once over 2–4 weeks part-time, spend ~$50–150 on launch ads, write no code yourself (Claude writes everything), then drop to ~1–2 hours/week of maintenance.

This plan is grounded in a 7-topic deep-research sweep (mid-2026 market meta, monetization benchmarks, discovery algorithm, solo-dev case studies, retention mechanics, policy/compliance, build tooling) plus a 3-concept design panel. Key findings that shape everything below:

- **The June 2026 discovery algorithm favors exactly this kind of game.** "Recommended For You" now optimizes 28-day retention (D1, D2–7, D8–28) instead of 7-day, and all ranking signals are per-user averages — a small game with engaged players competes evenly with giants. Daily-return hooks (offline progress, streaks, collections) are what earn free homepage traffic now.
- **Passive income = systemic content, not authored content.** Games whose replayability comes from systems (procedural variety, infinite rebirth ladders, collection matrices) run for years with near-zero updates (Tower of Hell: 24.3B visits, zero content updates). Games that need new pets/zones/maps die in months without a weekly treadmill.
- **Monetization benchmarks:** simulators/collection idles earn ~0.8–2.2 R$/visit (obbies only ~0.3). Best practice: 4–6 gamepasses on a round-number ladder (100/250/500/1000 R$), friction-removers convert 2–3× better than cosmetics, 2x multipliers are the single highest-converting pass, consumable dev products should be 30–40% of the offer surface. Devs keep 70% of Robux; DevEx pays $0.0038/R$ (**$0.0054/R$ if you're a verified US 18+ creator** — do this verification). Creator Rewards pays a flat **5 R$/day per "Active Spender"** who plays your game 10+ min as one of their first 3 games that day — the truly passive stream. Rewarded video ads unlock at 2,000 unique monthly visitors.
- **Honest base rate:** ~85% of monetizing Roblox devs earn <$100/month. The design maximizes the odds of the $800–3,000/month "success" tier (top ~15%) and keeps a tail open, but the modal outcome of any single Roblox game is near-zero. Mitigation: systemic design + a reusable codebase so a second game costs a fraction of the first.
- **Compliance (May 2026 loot-box rules):** any random outcome purchasable with Robux (or Robux-purchasable currency) must display exact odds summing to 100%, updating dynamically when luck boosts are active, gated via `PolicyService:GetPolicyInfoForPlayerAsync()`. The design keeps every paid product deterministic and shows a live odds panel anyway (it doubles as a gameplay/trust feature).

**Concept selection:** three concepts were designed and judged — an incremental obby (cheapest build, but ~0.3 R$/visit in the most saturated lane), a fish-breeding aquarium sim (strongest moat, but a 150–250h build that blows the 2–4 week budget), and a geode-mining collection idle. **Winner: the geode game**, with the fish game's compliance stance grafted in (paid = deterministic only) and scope trimmed to ~50–70 hours. The obby is noted as a cheap second game later, reusing this codebase's modules.

## The game: **Crack a Geode! [Mining Simulator]**

*(Title = brand hook + searchable genre keyword, 34 chars — Roblox semantic search rewards `[keyword] + unique hook` under 50 chars.)*

**One-liner:** Mine glowing geodes, crack them open in a slow-mo rarity reveal, grow your best crystals on racks **while you're offline**, and Recrystallize to dig ever deeper — all content is generated by systems, so it never needs weekly updates.

### Core loop (minute-to-minute)
1. **Spawn 3 steps from the mine wall.** One-tap/click mining pops geodes out with juicy feedback. First geode in hand within ~15 seconds — no tutorial, no menus (sub-60s bounce is a top negative ranking signal).
2. **Crack Station:** 2-second slow-mo reveal with rarity-colored burst (Common gray → Celestial rainbow). The first "Rare" is pity-timed to land inside the first 90 seconds. This reveal is the engineered TikTok moment.
3. **Per crystal, choose:** SELL for coins, or SOCKET on a growth rack where it grows in size/value in real time **including offline** (computed from saved timestamp on rejoin; 8h cap free, 24h with a gamepass).
4. **Spend coins:** better pickaxes, bigger backpack, more rack slots, deeper wall access.
5. **Recrystallize (rebirth):** reset coins/tools for a permanent multiplier (1.25× → 1.5× → 2×…, infinite formula ladder) and unlock the next cave layer — same systems, deeper rarity pool.

### Content is a data table, not authored assets
- **8 base crystal types × 6 mutations (Shiny, Frozen, Radioactive, Molten, Void, Celestial) = 48 collection-index entries at launch** — rendered by recoloring/retexturing a handful of meshes. Adding a row to a config table = 6 new collectibles (this is the whole "content update" workload later).
- **Procedural urgency replaces live-ops:** clock-synced 5-minute shop restock, 24h Daily Deal, and random 3–5 min server-wide events (Meteor Shower = big luck boost, Aurora = mutation chance) make every session time-sensitive with zero developer intervention.
- **Retention stack:** offline growth (the daily-return trigger), infinite rebirth ladder (months of goals from one content set), collection index with completion rewards, official free Engagement Rewards package (day 7/14/30 login streaks), group-join 2× daily bonus, global leaderboards (rebirths, rarest find). Sessions naturally exceed 10 minutes (rack timers + event cadence) — the Creator Rewards qualification bar.
- **Hard scope walls (each would multiply maintenance):** no pets, no trading at launch (v1.1 candidate only if retention data justifies it), no PvP, no limited-time authored content.

## What gets built in this repo (branch `claude/roblox-passive-income-game-0vqqoc`)

**Stack:** Rojo project (code-as-files, Git as source of truth) + Wally for the ProfileStore dependency (session-locked player data — 2026 best practice; prevents dupe/data-loss disasters) + StyLua/selene for lint. **The entire game — including the cave map, which is generated procedurally by a builder script — lives in code**, so you never have to build anything by hand in Studio.

```
default.project.json          # Rojo project mapping
wally.toml                    # ProfileStore dependency
src/
  shared/Config/
    Crystals.luau             # 8 bases × 6 mutations, rarity weights, values
    Monetization.luau         # ← you paste gamepass/product IDs here (only file you touch)
    Balance.luau              # all tuning constants in one place
  server/
    MapBuilder.luau           # procedurally builds cave, mine wall, crack station, racks
    MiningService.luau        # tap-to-mine loop, geode drops, pity timer
    CrackService.luau         # rarity rolls, reveal orchestration, odds source of truth
    RackService.luau          # growth + offline progress from saved timestamps
    RebirthService.luau       # infinite multiplier ladder, layer gating
    ShopService.luau          # clock-synced 5-min restock, 24h Daily Deal
    EventService.luau         # Meteor Shower / Aurora random server events
    DataService.luau          # ProfileStore profiles, session locking
    MonetizationService.luau  # pass/product grants, receipt processing (idempotent)
    PolicyGuard.luau          # PolicyService gating for paid-random surfaces
    Leaderboards.luau         # global rebirths + rarest-find (OrderedDataStore)
    AnalyticsService.luau     # funnel/bounce/D1 custom events
  client/
    UI/ (mobile-first)        # HUD, crack reveal, odds panel, index, shop, rebirth, streaks
    Effects/                  # reveal burst, mining feedback, event visuals
SETUP.md                      # your step-by-step operator guide (below, expanded)
```

Build sequence (part-time, AI-writing-code throughout):
- **Week 1 — playable core:** map builder, mining, crack reveal + odds panel, sell, coins, upgrades, ProfileStore data. *Milestone: fun for 10 minutes in Studio playtest.*
- **Week 2 — retention layer:** growth racks + offline progress, rebirth ladder, collection index, shop rotation, one server event, streaks package, group bonus, leaderboards.
- **Week 3 — money + polish:** all 6 passes + 7 products wired with placeholder IDs, PolicyService gating, mobile UI pass, analytics events, second event type, sound/juice on the reveal.
- **Week 4 — ship:** private soft-launch, fix what playtests surface, publish + store page, start TikTok clips.

## Revenue expectations (honest)

- **Modal outcome (~60–70%):** <$100/month — the platform base rate; priced in.
- **Success (~25%, if D1 ≥30% and the 28-day algorithm feeds it):** 5–10K visits/day at 1–2 R$/visit ≈ **$800–3,000/month** within 3–6 months (sales + Creator Rewards + ads).
- **Strong (~3–5%):** sustained 500–1,500 CCU ≈ **$2,500–5,000+/month**.
- **Tail (<1%):** viral reveal clip → 10K+ CCU → $20–30K/month; correct move then is the Grow-a-Garden path (partner with/sell to a scaling studio, not solo live-ops).
- Cashout: 30,000 R$ minimum (~$114); plan on 6–12 months of compounding before it feels passive. If this game stalls, the second swing (**Easy Obby: +1 Jump**, the runner-up concept) reuses DataService/MonetizationService/streaks/leaderboards and costs a fraction of the effort.
