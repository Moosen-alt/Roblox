# Crack a Geode! — Setup & Launch Guide

Everything in this repo is the complete, working game. **You never write code** — the world itself
is generated by a script when the server starts, so there is nothing to build by hand in Studio.
Your job is the ~2–3 hours of account clicking that only the game owner can do, listed below in order.

---

## Step 1 — Accounts (one-time, ~20 min)

1. Log into (or create) your Roblox account at roblox.com.
2. **Create a Group** (roblox.com → Create → Group, costs 100 Robux). Publish the game under the
   group — this gives you cleaner revenue accounting and powers the in-game "join the group for 2x
   daily rewards" bonus.
3. Note your **Group ID** (the number in the group page URL, e.g. `roblox.com/groups/12345678/...`
   → `12345678`).

## Step 2 — Open the game in Studio (~15 min)

1. Install **Roblox Studio** from create.roblox.com.
2. Download `build/game.rbxlx` from this repo and open it in Studio (File → Open from File).
3. File → **Publish to Roblox As...** → choose your group → name it:
   **`Crack a Geode! [Mining Simulator]`**
4. In Studio: Game Settings → Security → enable **"Enable Studio Access to API Services"**
   (lets you test data saving in Studio).
5. Press **Play** and sanity-check: you spawn in the cave, tapping a glowing wall node pops a
   geode, the Crack station opens with the odds panel, cracking works, racks accrue coins.

> Developing further: install [Rokit](https://github.com/rojo-rbx/rokit), run `rokit install`,
> then `rojo serve` + the Rojo Studio plugin to live-sync `src/` into Studio. Only needed when
> changing code — the committed `build/game.rbxlx` is always openable directly.

## Step 3 — Store page (~30 min, matters a lot)

**Paste-ready name, description, and icon/thumbnail shot list: [`marketing/store-page.md`](marketing/store-page.md).**

On create.roblox.com → your experience:

- **Name:** `Crack a Geode! [Mining Simulator]` — keep the bracketed genre keyword; Roblox
  search is semantic and the genre keyword is your cheapest discovery channel.
- **Description:** first line = the hook ("Crack glowing geodes, collect rare crystals, and your
  racks keep earning WHILE YOU SLEEP!"). Mention: offline earnings, 48 crystals to collect,
  rebirths, luck events.
- **Icon + thumbnails:** take real screenshots of the crack-reveal moment (rarity burst on
  screen). Never use misleading art — the algorithm suppresses metadata that mismatches gameplay.
- **Genre:** Simulation. **Devices:** enable Computer, Phone, Tablet (the UI is mobile-first).
- Complete the **age guidelines questionnaire**. Note: the game sells random-content items
  (geodes) for an earnable currency — answer the "paid random items" question **yes** so Roblox
  rates it correctly (the game already shows exact odds and policy-gates restricted players).
- Servers: default max players (the mine wall supports a full server) — 20 is fine.

## Step 4 — Monetization products (~40 min)

Create these on the experience page (Monetization → Passes / Developer Products), then paste each
numeric ID into **`src/shared/Config/Monetization.luau`**, rebuild/republish (or edit the same
values via Studio: ReplicatedStorage → Shared → Config → Monetization).
Also set `GroupId` at the top of that file.

Gamepasses (Monetization → Passes):

| Name | Price |
|------|-------|
| Auto-Crack | 100 |
| 2x Coins | 250 |
| 2x Luck | 350 |
| Triple Crack | 450 |
| Auto Swing | 450 |
| Overnight Miner | 500 |
| VIP Geode Baron | 1,000 |

**Auto Swing** removes the tapping: hold the button down and the pickaxe keeps swinging at
whatever you're pointing at. It is deliberately a *hold*, not an auto-clicker — you still aim,
you still pick the rock, you still have to be there — and because the server's mine cooldown
paces the swings either way, it can never out-earn a very fast tapper. It just means nobody
has to be one. It ships with `Id = 0`, which hides it from the store until you paste a real ID
in; everything else already works, so test it first by adding your own UserId to
`Monetization.CompUserIds`.

Developer Products (Monetization → Developer Products):

| Name | Price |

| Coin Chest | 500 |
| Coin Vault | 1,000 |

Until IDs are pasted, those offers are simply hidden in-game — nothing breaks.

Also enable a **Private Server** subscription at **99 Robux/month** (Access & Pricing settings).
⚠️ Set the price once and never change it — repricing cancels every active subscription.

## Step 5 — Verification & payouts (~20 min + ID check)

- Complete **ID verification** on your account (unlocks DevEx eligibility, Audience Expansion
  rewards from share links, and ads later).
- If you are a US-based creator aged 18+, complete the enhanced verification — eligible purchases
  then cash out at **$0.0054/Robux instead of $0.0038** (~42% more).
- DevEx minimum is 30,000 earned Robux (~$114). Payouts via create.roblox.com → DevEx.

## Step 6 — Launch playbook

1. **Soft launch:** publish publicly, tell nobody, watch Analytics (create.roblox.com →
   Analytics) for 3–5 days. The built-in funnel (FirstGeode → FirstCrack → FirstRare →
   FirstSocket → FirstRebirth) shows exactly where new players drop off; fix the biggest
   drop-off by tweaking `src/shared/Config/Balance.luau` constants.
2. **Content channel:** post the crack-reveal moment (screen-record a Celestial/Opal reveal) to
   TikTok + YouTube Shorts 3–5x/week. This is the channel that built every 2025–26 Roblox hit,
   and it costs $0. Eight ready-to-shoot scripts with hooks, shot lists, and captions:
   [`marketing/tiktok-scripts.md`](marketing/tiktok-scripts.md).
3. **Ads gate — do not skip:** only spend your ad budget once **D1 retention ≥ 30%** and most
   first sessions exceed 60 seconds (both visible in Analytics). The recommendation algorithm
   ranks you only on organically-acquired players, so ads on an unretentive game are burned money.
4. **Ads:** Creator Hub → Ads Manager → Sponsored Experience, auto-bid, ~$0.02–0.05 per play.
   Spend $50–150 across 1–2 weeks as a seeding test, not all at once.
5. **Updates:** for the first 8 weeks, ship one small weekly "update" (a new crystal row in
   `Crystals.luau` = 6 new collectibles, or a balance tweak) — each update re-triggers the
   discovery algorithm's explore phase. After that, ~monthly config updates from the
   1–2 h/week maintenance budget.

## Playtest checklist (before every publish)

- [ ] New player: first geode in <15s, first crack works, odds panel shows percentages
- [ ] Third crack ever is Rare or better (pity roll)
- [ ] Socket a crystal, leave, rejoin: welcome popup reports offline coins; Collect works
- [ ] Rebirth at 10,000 coins: resets run, +25% coins, layer 2 announced, crystals kept
- [ ] Shop restock timer counts down; buying works; daily-deal slot is discounted
- [ ] With a test purchase (Studio test mode): coin pack grants, starter pack grants once only
- [ ] Mobile emulator (Studio → Device tab): all buttons reachable, text readable

## Revenue expectations (honest)

Most Roblox games earn under $100/month — that is the base rate, priced in. The success path
(D1 ≥ 30% + the 28-day retention algorithm picking it up) is $800–3,000/month within 3–6 months;
the strong tier (~top 3–5% of devs) is $2,500–5,000+/month. Give it 6–12 months of light
compounding before judging, and if a reveal clip ever goes viral, the play is partnering with a
scaling studio — not solo live-ops.
